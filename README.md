# Task Workflow Agent

Консольный AI-агент для управления задачами.

Модель сама выбирает нужный инструмент: добавить задачу, показать список, сменить статус, найти просроченные и сделать summary за день.

## Возможности

- Добавление задач с опциональным дедлайном
- Просмотр задач (всех или по статусу)
- Смена статуса: `todo` / `doing` / `done`
- Список просроченных задач
- Краткий summary
- История диалога в `chat.json`
- Команды `сброс` и `выход`

## Стек

- Python 3
- OpenAI API (function calling / tools)
- JSON для хранения задач и истории
